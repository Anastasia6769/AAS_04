* Что происходит с загрузкой CPU при увеличении количества одновременно работающих потоков?

При увеличении количества потоков загрузка процессора возрастает. В моём эксперименте при одном потоке загрузка составляла 40%, а при восьми потоках достигла 99%.

* Почему после некоторого количества потоков дальнейшее увеличение не обязательно продолжает заметно повышать загрузку?

У процессора есть ограниченное количество вычислительных ресурсов. Когда они почти полностью заняты, добавление новых потоков не обязательно увеличивает загрузку. Потоки также могут конкурировать за ресурсы процессора.

* Физические ядра: 8.
* Логические процессоры: 8.

Количество физических ядер и логических процессоров может отличаться, потому что одно физическое ядро некоторых процессоров может обрабатывать несколько потоков выполнения. В моём случае количество физических ядер совпадает с количеством логических процессоров.

## Шаг 7. Частота процессора

В простое частота процессора составляла примерно 1913 МГц, а во время вычислений увеличилась до 2727 МГц. Базовая частота не была указана.

Частота процессора может изменяться в зависимости от нагрузки, температуры и других условий. Под нагрузкой процессор может увеличивать частоту для выполнения вычислений.

## Итоговый вопрос
У компьютера 4 физических ядра, 8 логических процессоров. Программа сообщает Environment.ProcessorCount == 8. Почему это не противоречие?

 Это не противоречие, потому что физические ядра и логические процессоры — разные понятия. Одно физическое ядро может поддерживать несколько логических процессоров. Поэтому программа может показывать 8 логических процессоров при наличии 4 физических ядер.

## Контрольные вопросы

1. Что показывает Environment.ProcessorCount?

Это свойство показывает количество логических процессоров, доступных программе.

2. Чем физическое ядро отличается от логического процессора?

Физическое ядро — это часть процессора, которая выполняет вычисления. Логический процессор — это вычислительный ресурс, который операционная система видит и может использовать для выполнения потоков.

3. Почему увеличение количества потоков может увеличить загрузку CPU?

Несколько потоков могут выполнять вычисления одновременно, поэтому процессор используется активнее и его загрузка увеличивается.

4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти?

Количество вычислительных ресурсов процессора ограничено. Когда процессор почти полностью загружен, новые потоки не обязательно увеличивают общую загрузку.

5. Почему частота процессора может изменяться во время работы?

Процессор автоматически изменяет частоту в зависимости от нагрузки, температуры и других условий. При выполнении сложных вычислений частота может увеличиваться.
